# RAM Control 1.2

[English documentation](README.md)

В верхней части окна есть переключатель English / Русский. Выбранный язык сохраняется в settings.json рядом с программой; папка должна быть доступна для записи. При первом запуске язык определяется по языку интерфейса Windows: русский для ru, иначе английский. Можно задать язык аргументом `-Language en` или `-Language ru`.

Исходники входят в комплект: RamControl.ps1 — логика приложения, RamNative.cs — вызовы Windows, MainWindow.xaml — интерфейс, locales/*.psd1 — переводы. Сборка вручную не нужна: Windows PowerShell 5.1 компилирует C# при запуске. Для файлов .ps1 и .psd1 сохраняйте UTF-8 с BOM.

В репозитории есть лицензия MIT, .gitignore и проверки GitHub Actions. Не добавляйте settings.json в Git. Значения памяти в версии 1.2 обозначены как МиБ (1 048 576 байт). Подробности системных ошибок Windows могут оставаться на языке самой ОС.

Windows 10/11. Распакуйте архив и откройте Start.cmd. Установка не нужна. Выберите процесс, введите целые мегабайты в Min RAM / Max RAM и нажмите «Применить».

## Показатели памяти

«RAM личная» — private working set: личные резидентные страницы процесса. «Всего WS» — полный рабочий набор, включая общие страницы. Оба значения читаются из одного снимка GetProcessMemoryInfo (PROCESS_MEMORY_COUNTERS_EX2); для старых Windows используется QueryWorkingSet. МБ в интерфейсе = 1 048 576 байт (MiB).

Раньше единственный столбец RAM показывал полный рабочий набор. Теперь показатели разделены. Если чтение личной памяти запрещено, показывается «—», а не ноль или другой показатель.

Для сравнения используйте вкладку «Подробности» диспетчера задач: одинаковый PID и столбец «Память (частный рабочий набор)». На вкладке «Процессы» приложения могут объединяться: ChatGPT (14) — группа из 14 процессов, а здесь каждая строка относится к отдельному PID. Группировка по приложениям в этой версии не реализована. Показатель активного частного рабочего набора может отличаться для приостановленных приложений. Обновление и округление тоже дают небольшие расхождения.

## Лимиты

Min RAM — мягкий минимум рабочего набора, не резервирование и не принудительное выделение памяти. Windows может требовать дополнительную привилегию для повышения минимума. Max RAM — жёсткий максимум полного рабочего набора (столбец «Всего WS»), а не всей выделенной/виртуальной памяти. Низкий максимум может увеличивать обращения к файлу подкачки и замедлять программу.

«Восстановить исходные» возвращает параметры до первого изменения в этой сессии. При обычном закрытии утилита также восстанавливает исходные параметры. При аварийном завершении лимит может оставаться до перезапуска целевой программы. Правила между запусками не сохраняются. Дочерние процессы не получают лимит автоматически.

«Активные» — процессы с главным окном, «фоновые» — остальные. Список обновляется каждые 2 секунды. Некоторые защищённые процессы Windows недоступны; для изменения параметров повышенного процесса могут потребоваться права администратора.

## Проверка

Запустите RamControl.ps1 с параметром -SelfTest для проверки чтения памяти, ввода и применения/восстановления лимита на временном дочернем процессе. Параметр -UiTest проверяет загрузку интерфейса, значения памяти, выбор процесса и поиск без открытия окна.
